# KASIRPRO AI — Demo Kasir UMKM

Aplikasi demo kasir berbasis HTML, CSS, dan JavaScript tanpa instalasi.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` menggunakan browser modern (Chrome, Firefox, Edge).
3. Data demo tersimpan pada `localStorage` browser/perangkat yang sama.

## Fitur yang sudah berjalan
- Dashboard omzet dan estimasi laba kotor
- Kasir POS dengan keranjang, stok, metode pembayaran, uang diterima, dan kembalian
- Pencatatan transaksi dan cetak struk
- CRUD produk, pencarian, kategori, dan penyesuaian stok
- Peringatan stok minimum
- Laporan omzet, HPP, laba kotor estimasi, pengeluaran, dan stok
- Catat/hapus pengeluaran
- Pengaturan nama usaha dan pajak
- Ekspor CSV dan backup JSON
- Responsive untuk layar kecil

## Batasan penting
Ini masih **demo lokal**, bukan aplikasi produksi multi-user. Data hanya berada di browser yang digunakan; belum ada login, database cloud, sinkronisasi antarperangkat, RLS, atau integrasi AI API. Untuk penggunaan bisnis nyata, perlu backend/database seperti Supabase, autentikasi, otorisasi server-side, dan pengujian keamanan.
